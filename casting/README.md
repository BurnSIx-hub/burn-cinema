# 🎭 Casting Call

**EN:** A scene-troupe manager for Foundry VTT. The GM builds "scenes" (troupes) with named roles backed by Actors; players pick a free role and automatically receive ownership of that Actor. Great for one-shots, tavern crowds and theatrical play. Russian and English localization included.

**Install:** Foundry VTT → Add-on Modules → Install Module →
```
https://github.com/BurnSIx-hub/casting-call/releases/latest/download/module.json
```

## Что это (RU)

Менеджер сценок для Foundry VTT: ГМ создаёт «сценки» — наборы ролей, привязанных к Actor'ам, — а игроки сами разбирают роли и автоматически получают владение соответствующим Actor'ом.

### Возможности

- 🎭 **Сценки-труппы** — ГМ создаёт сценку (например «Таверна», «Тронный зал») и перетаскивает в неё Actor'ов как роли
- 👤 **Выбор роли игроком** — игрок видит свободные роли, читает описание (из biography Actor'а) и занимает понравившуюся
- 🔑 **Автовладение** — заняв роль, игрок получает права на Actor'а; освободил — права снимаются
- 📣 **Активация сценки** — активная сценка автоматически открывается у всех игроков
- 🔄 **Смена ролей, освобождение всех ролей одним кликом (ГМ)**

### Как пользоваться

1. ГМ: кнопка 🎭 на левой панели инструментов → «Новая сценка»
2. Перетащите Actor'ов в сценку, дайте ролям названия («Кузнец», «Трактирщик»…)
3. Включите «Активна (видна игрокам)» — окно выбора само откроется у игроков
4. Игроки выбирают роли и играют; ГМ может освободить любую роль или все сразу

### Установка вручную

Скачайте `module.zip` из [последнего релиза](https://github.com/BurnSIx-hub/casting-call/releases/latest) и распакуйте в `FoundryVTT/Data/modules/casting-call/`.

Требования: Foundry VTT v13–v14.
