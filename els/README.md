# Epic Loading Screens

**EN:** Replaces the black loading screen between scenes in Foundry VTT (v13–v14) with custom artwork and rotating GM lore tips. Images are picked at random; tips support HTML and cycle every few seconds.

**Install:** Foundry VTT → Add-on Modules → Install Module →
```
https://github.com/BurnSIx-hub/epic-loading-screens/releases/latest/download/module.json
```

---

## 🚀 Установка

### Через Foundry (рекомендуется)

**Add-on Modules → Install Module** → вставьте ссылку на манифест (см. шапку).

### Вручную

1. Скачайте `module.zip` из [последнего релиза](https://github.com/BurnSIx-hub/epic-loading-screens/releases/latest) и распакуйте в `Data/modules/epic-loading-screens/`
2. Запустите Foundry и активируйте модуль в настройках мира

После установки добавьте свои изображения в папку `images/` (или укажите URL в настройках).

Другие модули автора: [BurnSIx-hub/foundry-modules](https://github.com/BurnSIx-hub/foundry-modules)

## ⚙️ Настройка — секции

Всё настраивается через интерфейс (ГМ), без правки кода. Откройте окно
**«Управление секциями»**: кнопка 🎞️ на панели инструментов сцены, либо
**Настройки → Настройки модуля → Epic Loading Screens → Управление секциями**.

**Секция** — это набор «изображения + записи ГМ». Например: секция «Город»
со скринами улиц и городскими слухами, секция «Подземелье» — с мрачными артами.

1. Создайте секцию, задайте название и префикс подсказок (например «Лорная запись»)
2. Добавьте изображения (выбор файла через FilePicker или URL)
3. Впишите записи ГМ — по одной на строку, можно с HTML
4. **Привяжите секции к сценам** — при загрузке сцены покажется её секция;
   сцены без привязки используют первую секцию в списке

## 🖼️ Изображения

- Поддерживаются форматы: JPG, PNG, WebP
- Можно указывать как локальные пути (`modules/epic-loading-screens/images/bg.jpg`),  
  так и полные URL (`https://example.com/image.jpg`)
- Изображение выбирается **случайно** при каждой загрузке сцены
- Размер: рекомендуется 1920×1080 или больше

---

## 💬 Подсказки ГМ

- Каждая подсказка — отдельная строка
- Поддерживается **HTML**: `<em>`, `<strong>`, `<span style="color:gold">`, и т.д.
- Подсказки **циклически сменяются** каждые ~7 секунд во время загрузки
- Показываются только если галочка «Показывать подсказки» включена

---

## 🎨 Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Минимальное время показа | 1 сек | Оверлей держится минимум это время |
| Скорость затухания | 800 мс | Плавность появления изображения |
| Показывать подсказки | Да | Включить/выключить полосу подсказок |
| Префикс подсказки | «Лорная запись» | Текст-заголовок над подсказкой (свой у каждой секции) |

## 🔧 Отладка

Откройте консоль браузера (F12) и используйте:

```js
// Принудительно показать оверлей
ELS.show(canvas.scene);

// Принудительно скрыть
ELS._hide();
```
