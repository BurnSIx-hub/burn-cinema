# 🔥 Осмотр предметов: открытый API

`game.burnCinema.inspect` появляется на хуке `ready`. Этот API нужен
внешним холстам, через которые 🔥 Cinema сам мышь не видит: мосту
3D Canvas из `burn-kartograf` и подобным. Модуль 🔥 Cinema про 3D ничего
не знает. Мост ищет предмет под курсором своими средствами и сообщает
это сюда.

Перед использованием проверяйте версию интерфейса:

```js
const api = game.burnCinema?.inspect;
if (!api || (api.apiVersion ?? 0) < 1) return; // старый 🔥 Cinema — молчим
```

| Поле | Что это |
|---|---|
| `apiVersion` | `1` — версия этого интерфейса. Растёт только при несовместимых изменениях. |
| `version` | Версия модуля burn-cinema, например `"1.3.2"`. |

## Зона

Зона — объект `{region, behavior, area}`: `region` — RegionDocument,
`behavior` — его RegionBehavior типа `burn-cinema.inspect`, `area` —
площадь региона в px². Зону получают только из `zoneAt` и `zoneOf`.
Самому её не собирать.

## Методы

### `zoneAt({x, y}) → zone | null`

Зона под точкой сцены, в пикселях сцены, не экрана. Правила те же,
что у 2D-щелчка:

- зона включена и стоит на этаже, который сейчас смотрит клиент (`canvas.level`);
- у игрока зона ещё не погашена режимом «один раз» для его персонажа;
- у игрока точка видна (туман, зрение токена);
- из вложенных зон побеждает меньшая.

У ГМа проверяются только этаж и включённость.

### `zoneOf(target, {point} = {}) → zone | null`

Зона по региону или поведению, когда предмет найден не точкой, а
лучом по модели. `target` — RegionDocument, RegionBehavior или
объект холста `Region` (берётся его `document`). У региона берётся
первое включённое поведение осмотра. Проверки те же, что у `zoneAt`,
кроме попадания в форму. Видимость проверяется, только если передана
`point`. Без `point` мост сам отвечает за то, что игрок видит предмет.

### `inspectZone(zone, {point, event} = {}) → Promise<boolean>`

Ровно то же, что щелчок по зоне в 2D:

- у ГМа — предпросмотр всех текстов и заметки;
- у игрока — проверка дальности, бросок навыка, если он нужен, и запрос
  ГМу. Текст придёт с клиента ГМа через сокет только адресатам и
  появится плашкой.

`point` — точка сцены, по ней выбирается ближайший свой токен, если
никто не выделен. По умолчанию — центр зоны. `event` уходит в
`actor.rollSkill`, чтобы Shift/Ctrl работали как обычно.

Перед действием зона перепроверяется через `zoneOf`. Возвращает `false`,
если зона уже недоступна, иначе `true`. `true` не значит, что текст
показан: ГМ может отказать по дальности или отсутствовать.

### `hover(zone | null, {element} = {})`

Сообщает зону под курсором с внешнего холста:

- показывает подпись с названием предмета;
- вешает класс `burn-inspect-cursor` (курсор-лупа) на `element` и
  снимает его с прошлого элемента;
- вызывает `Hooks.callAll("burnCinema.inspectHover", zone | null)`.

Повторный вызов с той же зоной и тем же элементом ничего не делает.
Хук срабатывает и при наведении в 2D.

### `setAnchor(fn | null)`

Задаёт, где на экране стоит зона. Функция
`fn(region) → {top: {x, y}, bottom: {x, y}}` возвращает пиксели экрана
(client): `top` — верх предмета, над ним встаёт подпись и плашка;
`bottom` — низ, туда плашка уходит, если сверху нет места. Если функция
вернула `null` (предмет за кадром), подпись и плашка прячутся, но
не закрываются. Так же действуют точки далеко за экраном: если и `top`,
и `bottom` дальше половины экрана за краем (например, `-10000` для
модели за камерой), это считается тем же `null`.

Пока функция задана, 2D-подсветка контура (PIXI) не рисуется:
подсвечивает внешний холст. `setAnchor(null)` возвращает расчёт по
2D-холсту.

### `reposition()`

Пересчитать подпись и плашку прямо сейчас. Звать каждый кадр внешнего
холста: в 2D это делает тикер PIXI, а при спрятанном `#board` он может
тикать редко.

### `closePlaque()`

Закрыть плашку. Например, по щелчку мимо зоны во внешнем холсте.

## Хук

`Hooks.on("burnCinema.inspectHover", (zone) => …)` — зона под курсором
сменилась. Приходит `zone` или `null`, как из 2D, так и из `hover()`.

## Чего API не делает

- Не отдаёт тексты зон. Они есть только у ГМа и уходят игроку с его
  клиента в момент осмотра (см. `FORMAT.md`).
- Не ловит мышь во внешнем холсте и не подсвечивает модель — это дело моста.
