# 🔥 Осмотр предметов: формат данных

Это спецификация для внешних инструментов (Картограф и др.), которые
выгружают сцены с готовыми зонами осмотра. Формат действует с burn-cinema
1.3.1. В 1.3.0 тексты лежали прямо в регионе, и модуль переводит такие
зоны сам (см. «Перевод 1.3.0»).

Зона состоит из двух частей:

1. **Регион с поведением** `burn-cinema.inspect` — форма зоны и
   публичные опции. Уходит всем клиентам вместе со сценой.
2. **Тексты** (текст осмотра, текст провала, заметка ГМа) — в отдельном
   JSON-файле в папке `burn-inspect-secret/` папки данных Foundry. Игроку
   они уходят только в момент осмотра и только адресату.

Связь между частями — `system.textKey`.

## Почему тексты не в регионе

Проверено по ядру Foundry 14.371 (`resources/app/dist`):

- `packages/world.mjs`: мир для клиента собирается через
  `db.<Тип>.dump()` без фильтра по пользователю. Сцены, журналы с
  ownership NONE, флаги, все настройки и шёпоты уходят каждому игроку.
- Компендий: индекс уходит всем, а чтение документов из пака сервер не
  проверяет по правам.
- Папка данных раздаётся по HTTP, но **без списка каталога**. Список файлов
  выдаёт только `FilePicker.browse`, и сервер (`files/files.mjs`) требует
  для него право FILES_BROWSE. По умолчанию оно есть у ролей «Доверенный
  игрок», «Ассистент» и «Мастер».

Поэтому файл текстов называется случайно (не меньше 128 бит), а его имя
нигде в мире не записано. ГМ находит файл просмотром папки, игрок с ролью
«Игрок» — нет. Окно «Осмотр предметов» предупреждает ГМа, если право
FILES_BROWSE есть у кого-то из игроков.

## Регион

- Форма зоны — это `shapes` региона: rectangle, ellipse, polygon, circle
  и любые другие формы ядра. Дыры (`hole: true`) вырезают места, где клик
  не срабатывает.
- Этажи задаёт поле `levels` региона. Пустой список значит «на всех этажах».
  Зона работает только на том этаже, который сейчас смотрит клиент.
- Поля `events` у поведения нет: клик ловит сам модуль хит-тестом по форме.

```json
{
  "name": "🔍 Кровать",
  "color": "#f3c76b",
  "visibility": 0,
  "levels": [],
  "shapes": [
    { "type": "rectangle", "x": 1250, "y": 800, "width": 200, "height": 100,
      "anchorX": 0.5, "anchorY": 0.5, "rotation": 0 }
  ],
  "behaviors": [
    {
      "type": "burn-cinema.inspect",
      "name": "🔥 Осмотр",
      "disabled": false,
      "system": {
        "textKey": "3f9c2a7be41d0c58",
        "title": "Кровать",
        "checkMode": "roll",
        "skill": "prc",
        "dc": 12,
        "visibility": "self",
        "range": 10,
        "repeat": "remember",
        "sound": "",
        "duration": 0
      }
    }
  ]
}
```

`visibility: 0` — это `CONST.REGION_VISIBILITY.LAYER`: контур региона виден
только на слое «Регионы». Игроки видят зону лишь при наведении, через
подсветку модуля.

### Поля `system` (публичные)

Все поля необязательны. Отсутствующее или неверное значение заменяется
значением по умолчанию (`normalizeSystem` в `inspect/scripts/logic.mjs`).
**Текстов здесь быть не должно**: поля `text`, `textFail`, `gmNote` в
`system` модуль считает данными 1.3.0, переносит в файл и стирает.

| Поле | Тип | По умолчанию | Смысл |
|---|---|---|---|
| `textKey` | строка `[A-Za-z0-9_-]{8,64}` | `""` | Ключ текстов зоны в файлах хранилища. Генерировать случайно, например 16 hex-символов. Пусто — у зоны нет текстов, игрок увидит «Ничего примечательного». |
| `title` | строка | `""` | Название предмета. Публичное: видно при наведении и шапкой плашки. Не класть сюда спойлеры. |
| `checkMode` | `none` \| `roll` \| `passive` | `none` | `roll` — игрок кидает навык (окно броска dnd5e). `passive` — пассивное значение навыка сравнивается с СЛ без броска. |
| `skill` | строка | `prc` | Ключ навыка dnd5e: `prc` (Восприятие), `inv` (Анализ), `ins`, `arc`, `his`, `nat`, `rel`, `sur`, `med` и др. |
| `dc` | целое 0–40 | `12` | Сложность. Успех — если результат ≥ `dc`. |
| `visibility` | `self` \| `all` \| `chat` | `self` | Кому показывать плашку: только осмотревшему; всем игрокам; осмотревшему плюс открытая запись в чат. |
| `range` | число ≥ 0 | `0` | Дистанция в единицах сцены (обычно футы) от центра токена до края зоны. `0` — без ограничения. Проверяет клиент ГМа. |
| `repeat` | `remember` \| `always` \| `once` | `remember` | `remember` — итог запоминается за персонажем, повторный клик показывает тот же текст без броска. `always` — каждый клик заново. `once` — после первого осмотра зона гаснет для этого персонажа. |
| `sound` | путь | `""` | Звук для тех, кому показана плашка. |
| `duration` | число ≥ 0 | `0` | Сколько секунд висит плашка. `0` — пока её не закроют или не щёлкнут мимо. |

## Файл текстов

Папка: `<папка данных Foundry>/burn-inspect-secret/` (источник `data`).
Модуль читает **все** `*.json` в ней.

```json
{
  "version": 1,
  "zones": {
    "3f9c2a7be41d0c58": {
      "text": "<p>Кровать будто котом изодрана, но кота тут нет.</p>",
      "textFail": "<p>Старая продавленная кровать.</p>",
      "gmNote": "<p>Это следы оборотня.</p>"
    }
  }
}
```

| Поле | Тип | Смысл |
|---|---|---|
| `text` | HTML или простой текст | Текст осмотра. При проверке навыка — текст успеха. |
| `textFail` | HTML или простой текст | Текст при провале. Пусто — «Ничего примечательного.» |
| `gmNote` | HTML или простой текст | Заметка только для ГМа: всплывает карточкой на экране ГМа при осмотре и видна в его предпросмотре. В мир не пишется. |

Имена файлов:

- `world-<id мира>-<32 hex>.json` — **главный файл мира**. Его пишет ГМ
  из редактора зоны. В нём остаются только ключи, которые есть в мире.
- Любое другое имя, например `kartograf-<32 hex>.json`, — выгрузка
  внешнего инструмента. Модуль её только читает. Если ключ есть и в
  выгрузке, и в файле мира, главнее файл мира: правка ГМа не теряется
  при повторной выгрузке.

**Требования к выгрузке:**

1. Случайная часть имени файла — не меньше 128 бит (32 hex-символа).
   Короткое или предсказуемое имя можно подобрать по HTTP.
2. Файл кладётся прямо в `burn-inspect-secret/`, а не в папку карты
   (`kartograf/<карта>/`), имя файла нигде в сцене не упоминается.
3. Ключи `textKey` — случайные и уникальные между картами. Если сцену
   выгружают заново поверх уже импортированной, ключи стоит сохранять:
   тогда правки ГМа из файла мира продолжат действовать.

## Перевод 1.3.0

При входе активного ГМа модуль сам:

1. читает сцены с сервера в сыром виде и находит поведения
   `burn-cinema.inspect` со старыми полями `text`, `textFail`, `gmNote`;
2. переносит их в файл мира под новым `textKey`;
3. заменяет `system` целиком (`ForcedReplacement`) только публичными
   полями, так что старые ключи исчезают из базы;
4. убирает заметку ГМа из шёпот-отчётов 1.3.0 в чате (сам отчёт остаётся).

Внешнему инструменту поддерживать формат 1.3.0 не нужно.

## Служебные флаги (не выгружать)

Память осмотров модуль хранит в `flags["burn-cinema"].inspectSeen` поведения:
`{ "a_<actorId>": { "o": "success"|"fail"|"plain", "u": "<userId>", "t": <ms> } }`.
Это состояние игры. Внешний инструмент его не пишет. При повторной выгрузке
поверх живой сцены этот флаг лучше не затирать.

## Совместимость

- Значения текстов можно давать простым текстом без HTML.
- Новые поля в будущих версиях будут только добавляться, с безопасными
  значениями по умолчанию.
