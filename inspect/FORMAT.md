# 🔥 Осмотр предметов: формат данных

Это спецификация для внешних инструментов (Картограф и др.), которые
выгружают сцены с готовыми зонами осмотра. Формат зафиксирован
2026-11-27, в первом выпуске burn-cinema после 1.2.2.

## Где лежит

Зона осмотра — обычный **регион** сцены Foundry v14. Внутри у него
**поведение** (RegionBehavior) типа `burn-cinema.inspect`.

- Форма зоны — это `shapes` региона: rectangle, ellipse, polygon, circle
  и любые другие формы ядра. Дыры (`hole: true`) вырезают места, где клик
  не срабатывает.
- Этажи задаёт поле `levels` региона. Пустой список значит «на всех этажах».
  Зона работает только на том этаже, который сейчас смотрит клиент.
- Подписка на события региона не нужна: поля `events` у поведения нет.
  Клик ловит сам модуль хит-тестом по форме.
- Если модуль burn-cinema выключен, Foundry не знает этот тип поведения.
  Регион при этом загрузится, а поведение будет помечено как недопустимое.
  Сцена от этого не ломается.

## Пример

```json
{
  "name": "🔍 Кровать",
  "color": "#f3c76b",
  "visibility": 0,
  "levels": [],
  "shapes": [
    { "type": "rectangle", "x": 1250, "y": 800, "width": 200, "height": 100,
      "anchorX": 0.5, "anchorY": 0.5, "rotation": 0 }
  ],
  "behaviors": [
    {
      "type": "burn-cinema.inspect",
      "name": "🔥 Осмотр",
      "disabled": false,
      "system": {
        "title": "Кровать",
        "text": "<p>Кровать будто котом изодрана, но кота тут нет.</p>",
        "checkMode": "roll",
        "skill": "prc",
        "dc": 12,
        "textFail": "<p>Старая продавленная кровать.</p>",
        "visibility": "self",
        "range": 10,
        "repeat": "remember",
        "gmNote": "<p>Это следы оборотня.</p>",
        "sound": "",
        "duration": 0
      }
    }
  ]
}
```

`visibility: 0` — это `CONST.REGION_VISIBILITY.LAYER`: контур региона виден
только на слое «Регионы». Игроки видят зону лишь при наведении, через
подсветку модуля.

## Поля `system`

Все поля необязательны. Отсутствующее или неверное значение заменяется
значением по умолчанию (`normalizeSystem` в `inspect/scripts/logic.mjs`).

| Поле | Тип | По умолчанию | Смысл |
|---|---|---|---|
| `title` | строка | `""` | Название предмета. Показывается подписью при наведении и шапкой плашки. Пусто — без подписи. |
| `text` | HTML | `""` | Текст осмотра. При проверке навыка это текст успеха. |
| `checkMode` | `none` \| `roll` \| `passive` | `none` | `roll` — игрок кидает навык (окно броска dnd5e). `passive` — пассивное значение навыка сравнивается с СЛ без броска. |
| `skill` | строка | `prc` | Ключ навыка dnd5e: `prc` (Восприятие), `inv` (Анализ), `ins`, `arc`, `his`, `nat`, `rel`, `sur`, `med` и др. |
| `dc` | целое 0–40 | `12` | Сложность. Успех — если результат ≥ `dc`. |
| `textFail` | HTML | `""` | Текст при провале. Пусто — «Ничего примечательного.» |
| `visibility` | `self` \| `all` \| `chat` | `self` | Кому показывать плашку: только осмотревшему; всем игрокам; осмотревшему плюс открытая запись в чат. |
| `range` | число ≥ 0 | `0` | Дистанция в единицах сцены (обычно футы) от центра токена до края зоны. `0` — без ограничения. |
| `repeat` | `remember` \| `always` \| `once` | `remember` | `remember` — итог запоминается за персонажем, повторный клик показывает тот же текст без броска. `always` — каждый клик заново. `once` — после первого осмотра зона гаснет для этого персонажа. |
| `gmNote` | HTML | `""` | Заметка только для ГМа. Приходит ему шёпотом при осмотре и видна в предпросмотре ГМа. |
| `sound` | путь | `""` | Звук для тех, кому показана плашка. |
| `duration` | число ≥ 0 | `0` | Сколько секунд висит плашка. `0` — пока её не закроют или не щёлкнут мимо. |

## Служебные флаги (не выгружать)

Память осмотров модуль хранит в `flags["burn-cinema"].inspectSeen` поведения:
`{ "a_<actorId>": { "o": "success"|"fail"|"plain", "u": "<userId>", "t": <ms> } }`.
Это состояние игры. Внешний инструмент его не пишет. При повторной выгрузке
поверх живой сцены этот флаг лучше не затирать.

## Совместимость

- Значения `title`, `text` и других полей можно давать простым текстом без HTML.
- Новые поля в будущих версиях будут только добавляться, с безопасными
  значениями по умолчанию. Старые выгрузки продолжат работать.
