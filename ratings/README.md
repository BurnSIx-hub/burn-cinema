# Session Ratings — мини-IMDB для глав (Foundry VTT)

Модуль, который превращает вашу кампанию в подобие IMDB: в конце сессии мастер
открывает голосование, и игроки оценивают прошедшую **главу** по 10-балльной шкале
и нескольким критериям. Модуль ведёт «зал славы» глав со средними оценками.

## Возможности

- **10 звёзд, как на IMDB** — оценка 1–10, средний балл вида `7.8 / 10`.
- **Критерии** — по умолчанию: Сюжет, Бои, Отыгрыш, Атмосфера. Настраиваются
  списком через запятую в настройках модуля (применяются к новым главам; каждая
  глава хранит свой набор критериев).
- **Анонимность + шифрование** — игроки видят только усреднённые баллы. Сырые
  оценки с именами хранятся в мире **зашифрованными** (AES-GCM 256); ключ лежит
  только в браузере мастера и по сети не передаётся. Игрок даже через консоль
  (`game.settings.get`) увидит лишь средние и нечитаемый шифр-блоб. **Мастер**
  расшифровывает локально: кнопка «Кто как проголосовал».
- **Постер и описание главы** — как карточка фильма.
- **Итоги в чат** — при закрытии голосования в чат падает карточка с результатами.
- Локализация RU / EN.

## Как пользоваться

1. Иконка «хлопушки» (🎬) на панели инструментов (слой заметок) — открывает окно
   «Оценки глав». Видна всем.
2. **Мастер:** «Новая глава» → название, постер, описание. Затем «Открыть
   голосование» — у всех игроков всплывает окно оценки.
3. **Игроки:** ставят звёзды по каждому критерию → «Отправить оценку». Можно
   переголосовать, пока голосование открыто.
4. **Мастер:** «Закрыть голосование» — итоги уходят в чат, глава попадает в зал
   славы с финальным средним баллом.

## Требования

- Foundry VTT v13+ (проверено на v14). Системо-независимый.
- Голоса хранятся в мире; записывает их мастер (нужен хотя бы один онлайн-ГМ в
  момент голосования). Игроки отправляют оценку мастеру по сокету.

> **Ключ шифрования.** Генерируется автоматически на машине мастера и хранится
> в client-scope настройке (localStorage). Кнопка «Ключ» (🔑) в шапке окна —
> посмотреть/скопировать ключ для бэкапа или импортировать его на другой машине.
> Потеряешь ключ — пропадёт только детальная раскладка по игрокам; средние баллы
> в мире сохранятся.
>
> **Что шифрование НЕ закрывает:** момент отправки голоса игрок→мастер идёт по
> сокету. Технически подкованный игрок, заранее повесивший слушатель сокета, мог
> бы перехватить голос в полёте — это уже не «консоль». Полная защита (в т.ч.
> передачи) потребует асимметричного шифрования; при желании добавим.

## API

```js
const api = game.modules.get("session-ratings").api;
api.open();               // окно «Оценки глав»
api.openVote(chapterId);  // окно оценки конкретной главы
```
